1. Зачем добавлять папку PHP в переменную PATH и как проверить, что PHP установлен? 
Добавив C:\php в PATH, можно вызывать php из любого окна CMD без указания полного пути. php -v 


2. Какой командой запускается встроенный сервер PHP и как указать другой порт или 
корневую папку? 
php -S localhost:8000
php -S localhost:8080
php -S localhost:8000 -t C:\projects\filemanager


3. Почему форма загрузки не работает без enctype="multipart/form-data"? 
multipart/form-data разбивает запрос на части


4. Какие ключи содержит массив $_FILES['userfile'] и что хранится в tmp_name? 
name
full_path 
type
tmp_name 
error 
size 
tmp_name - путь к кэшу в системной папке Temp, который удаляется после завершения скрипта


5. Чем move_uploaded_file() отличается от copy()? 
move_uploaded_file() дополнительно проверяет, что файл действительно загружен через HTTP POST
copy() просто копирует любой файл без проверки


6. Чем отличаются директивы upload_max_filesize и post_max_size? Какое значение 
должно быть больше и почему? 
upload_max_filesize - предел одного файла, post_max_size - предел всего POST-запроса. Должно выполняться post_max_size > upload_max_filesize, потому что запрос может содержать несколько файлов и другие данные



7. Что произойдёт с массивами $_POST и $_FILES, если запрос больше post_max_size? 
PHP полностью отбросит тело запроса: $_POST и $_FILES станут пустыми массивами


8. Почему upload_max_filesize нельзя изменить через ini_set()? 
Эти директивы обрабатываются PHP до запуска скрипта - на этапе приёма HTTP-запроса. К моменту выполнения ini_set() файл уже принят или отброшен


9. Для чего при удалении и сохранении файлов используется basename()? 
basename() отбрасывает путь и оставляет только имя файла


10. Почему нельзя разрешать загрузку файлов с расширением .php?
Файлы .php - исполняемые скрипты. Если их загрузить можно выполнить произвольный код
